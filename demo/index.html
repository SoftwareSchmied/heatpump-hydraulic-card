Heatpump Flow Card

Live demo with simulated heat pumps – no Home Assistant needed. Pick a heat pump and an operating state.

GitHub repository and docs Install via HACS Preset feedback Community thread
Your system asks for reduced motion, so the card shows no animations – just like it would in Home Assistant. To see the flow, turn animations back on in your operating system (Windows: Settings → Accessibility → Visual effects → Animation effects).

Click any part of the card: in Home Assistant it opens the more-info dialog of that entity.

Heat pump

Only the Lambda preset is tested on a real installation. The others are built from the integrations' source code – feedback welcome.

Layout

Wide puts the tiles beside the schematic when the card is wide enough; compact saves space in narrow columns; wall display uses large type and hides the controls until you touch the card.

Unit drawing

Automatic uses the drawing of the preset (Lambda, Vaillant); other heat pumps keep the generic fan. Vaillant comes in three sizes. Ground and groundwater sources keep their loop symbol.

Colours

Every colour is a CSS variable (--hfc-*) you can set in a theme or with card-mod.
